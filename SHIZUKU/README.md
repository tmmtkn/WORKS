# SHIZUKU — しずく

自然の葉に並ぶ雫をなぞり、和音と旋律をつくるブラウザ作品。

## 公開作品

[GitHub Pagesでしずくを開く](https://tmmtkn.github.io/WORKS/SHIZUKU/?sound=media)

[Sites版](https://shizuku-trace-1025.greenhaven20.chatgpt.site/?sound=media)

## 操作

- 「触れて、はじめる」で音を開始します。
- 葉の雫をマウスで押しながら、または指でなぞります。雫ごとに4音の柔らかな和音が鳴ります。
- 指を離すと、辿った順番をもとに拍を整えた旋律と伴奏が流れ、最後に短い終止フレーズが続きます。
- 曲の終了後だけ「もう一度聴く」が現れます。次の演奏は、そのまま雫をなぞり直せます。
- 音のON/OFFは右上にあります。葉と点の表示は演奏・再生に応じて自動で切り替わります。
- キーボードでは演奏面を選び、矢印で雫を選択、Spaceで演奏、Enterで旋律を再生します。
- 音の開始に失敗したときだけ、確認音と標準の音声プレイヤーを含む案内が現れます。

## ローカルで開く

ビルドや依存ライブラリのインストールは不要です。WORKSのルートでサーバーを起動し、次のURLを開きます。

```sh
python3 -m http.server 8000
```

http://localhost:8000/SHIZUKU/?sound=media

Safariでは通常の音声ファイルを使う方式を自動選択します。`?sound=media` を付けると、ほかのブラウザでも同じ方式を使えます。

## 構成

```text
WORKS/
├── YOBANA/
└── SHIZUKU/
    ├── index.html
    ├── style.css
    ├── app.js
    ├── music.js
    ├── media-audio.js
    └── assets/
        ├── leaf.png
        └── confirmation.wav
```

Canvas 2Dで写真内の雫と反応位置を合わせ、音が鳴った雫の周囲に、葉脈に沿って枝分かれしながら消える濡れた光を描画します。音楽のコード進行・和音・終止フレーズは `music.js`、Safari向けのPCM音声生成と再生は `media-audio.js` にあります。写真風の葉の画像は、この作品用にAI生成したものです。

Sitesの管理設定・認証情報・入れ子のGitリポジトリは含みません。GitHub PagesではYOBANAの既存のルートURLを保ち、しずくは `/WORKS/SHIZUKU/` で公開します。

## 葉脈の光

光の表現は、枝分かれする繊細な線を使う `e4f599d` の版へ戻しています。画像抽出版は不採用とし、細い線の色・太さ・ぼかし・時間変化を基準として維持します。

## 経路の位置合わせ

繊細な線の描画は維持し、`veins.js` に背景画像の原寸座標で測った葉脈の曲線を保存しています。ランダムな線の変形を取り除き、各雫を最も近い曲線へ接続します。雫間を移動する光は使わず、なぞったときも旋律の再生中も、発音した雫の周囲だけを光らせます。光の筋は細さと時間変化を保ち、少し強くしています。

## 雫ごとに固定する和音の試作

変更前はGitタグ `shizuku-time-chords-v1`（`1a53e55`）に保存しています。

現在の標準は、雫の位置と大きさから決めた固定の4音和音です。同じ雫は触れる時間や順番によらず同じ和音になり、大きな雫は低い音域になります。和音は共通のペンタトニックの音から構成し、自由に重ねられるようにしています。指を離したあとの旋律・伴奏・終止フレーズは変更していません。

比較用に、URLへ `&harmony=flow` を付けると従来の時間で変わる和音を使えます。
