# YOBANA

文字が光と音になって夜空にほどける、ブラウザで動くインタラクティブ作品。

## 試す

`index.html` をブラウザで開くだけで動きます。インストールやビルドは不要です。

ローカルサーバーを使う場合は、WORKS リポジトリのルートで以下を実行し、 http://localhost:8000/YOBANA/ を開きます。

```sh
python3 -m http.server 8000
```

## 操作

- 入力欄に文字を打つと、一文字ずつ花火になります。日本語は変換を確定したときに打ち上がります。
- 「音をひらく」でガラス・ベル系の生成音が有効になります。
- マウス移動、または夜空を指でドラッグすると視点が変わります。
- 「視点をとめる」でカメラを固定できます。
- 「ひとひら試す」でデモ、「消す」で夜空と入力をクリアします。
- Enter で入力欄を空にできます。

## 仕組み

Canvas 2D に三次元座標を透視投影し、カメラの旋回・上下移動・距離の変化を表現しています。粒子と軌跡を空間内に保持するため、視点を動かすと奥行きによる見え方が変わります。音は Web Audio API で生成します。

外部ライブラリ・外部素材・通信処理はありません。入力したことばはブラウザ内で処理されます。
OS の「動きを減らす」設定が有効な場合、自動視点移動を初期状態で停止し、粒子数を減らします。

## 配置

```text
WORKS/
└── YOBANA/
    ├── index.html
    └── README.md
```

Sites 固有の設定や認証情報を含まない、独立した作品フォルダです。
