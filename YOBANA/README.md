# YOBANA

文字が光と音になって夜空にほどける、ブラウザで動くインタラクティブ作品。

## 試す

インストールやビルドは不要です。音声ファイルを読み込むため、ローカルサーバーから開いてください。

ローカルサーバーを使う場合は、WORKS リポジトリのルートで以下を実行し、 http://localhost:8000/YOBANA/ を開きます。

```sh
python3 -m http.server 8000
```

## 操作

- 入力欄に文字を打つと、一文字ずつ花火になります。日本語は変換を確定したときに打ち上がります。
- 「音をひらく」で開花に合わせてゆっくり広がるアンビエント音が有効になります。
- マウス移動、または夜空を指でドラッグすると視点が変わります。
- 「視点をとめる」でカメラを固定できます。
- 「ひとひら試す」でデモ、「消す」で夜空と入力をクリアします。
- Enter で入力欄を空にできます。

## 仕組み

Canvas 2D に三次元座標を透視投影し、カメラの旋回・上下移動・距離の変化を表現しています。粒子と軌跡を空間内に保持するため、視点を動かすと奥行きによる見え方が変わります。音は Web Audio API でローカル録音の余韻を粒状に分解し、低速で重ねてアンビエント音に変化させます。打ち上げ時の効果音はありません。

外部ライブラリはありません。音声素材は作品フォルダに同梱し、外部サーバーへ通信しません。入力したことばはブラウザ内で処理されます。音源と利用条件は assets/audio/CREDITS.md を参照してください。
OS の「動きを減らす」設定が有効な場合、自動視点移動を初期状態で停止し、粒子数を減らします。

## 配置

```text
WORKS/
└── YOBANA/
    ├── index.html
    ├── README.md
    └── assets/audio/   # 実録の花火音と出典
```

Sites 固有の設定や認証情報を含まない、独立した作品フォルダです。

## 別案のプレビュー

`film.html` は「光の薄膜」の方向性を比較するための独立した試作です。ローカルサーバーで `/film.html` を開いてください。WebGLで透ける光の膜を描き、入力文字が膜の曲面に沿って浮かび、入力地点からたわみが伝わります。音は現在のアンビエント表現を共有します。本体の `index.html` は変更していません。

`film-fireworks.html` は「膜のなかの花火」の試作です。元の球状花火と文字の光を使い、前面の薄い膜に開花位置からたわみが伝わります。膜の色と濃度は控えめにし、アンビエント音を共有しています。元の2案は変更していません。

膜と花火の試作では、両者が同じ三次元座標とカメラを使います。開花の球状の広がりで膜を変形し、花火の色を膜へ反射させます。上昇中の光や膜の近くの火花も局所的に膜を照らします。

膜は現在、一枚の面ではなく、各花火の周囲に異なる向きで膨らむ局所的な曲面として描いています。輪郭を淡く消し、花火の色・光・広がりと連動して重なり、消えていきます。

描画は、火花の軌跡をまとめて描き、座標計算を共有するよう軽量化しています。膜は局所曲面ごとに光を計算し、背景タブではアニメーションを停止します。

現在の確認対象は `film-fireworks.html`。「膜のなかの花火」と、整列した細かなドットの膜を組み合わせたビジュアルを仮止めしています。Gitタグ `yobana-visual-v3` で戻せます。

- 入力前も、左右へ広がる薄い膜がゆっくり波打ちます。
- 花火の周囲に異なる向きの曲面が現れ、花火の色に合わせてドットと膜が光ります。
- 膜の縁は柔らかく消え、色・濃淡・彩度が穏やかに変化します。
- 日本語の変換確定では打ち上げず、確定後の別のEnterで言葉を送ります。
- 現在の音はアンビエント版です。実録の花火音を使う保存版は `yobana-prototype-v2` です。

以後は、このビジュアルを基準にして変更を進めます。

## 音の調整（ビジュアル仮止め後）

`film-fireworks.html` は、実録の花火音を使い、立ち上がりを柔らかくして高い成分を抑えた音を試しています。開花に同期する音と火の粉を残し、長めの柔らかな残響を加えています。打ち上げ音は小さく、元の速さで再生します。ビジュアルと入力操作は `yobana-visual-v3` のままです。他のプレビューの音は変更していません。

## ビジュアル・音の仮止め（2026-10-24）

`film-fireworks.html` のビジュアルと音を合わせた状態を、Gitタグ `yobana-prototype-v4` として保存しています。ビジュアルは `yobana-visual-v3` を維持し、音は柔らかく整えた実録の開花音と火の粉に、5.2秒の暗い残響を重ねています。

## ピアノ音の試作

`film-fireworks.html` は現在、開花に合わせて実録ピアノの余韻が立ち上がる音を試しています。相性のよい音階を共有し、複数の花火で響きが重なります。打ち上げの効果音は鳴らしません。音源の出典・ライセンスは `assets/audio/piano/CREDITS.md` とプレビュー内の「音源」リンクに記載しています。ビジュアルは仮止め版を維持しています。

ピアノの試作では残響を少し豊かにし、最後の花火が消えてから短い4音の旋律が一度だけ流れます。新しい言葉を打ち上げた場合は、その旋律を止めて最後へ延期します。「消す」や音の無効化でも旋律を取り消します。

## 言葉から生まれる締めくくり（試作）

変更前のピアノ版は `yobana-piano-v5`（`a780ba2`）に保存しています。現在は、直近に送った言葉の最初・中ほどの文字に対応する音から、あらかじめ整えた4音の短い終止旋律を選びます。同じ言葉は同じ音と間隔に対応し、最後の2音はミからドへ静かに着地します。最後の音は開始から1.7秒で鳴り、小さな低音のドとソが響きを支えます。新しい言葉を送ると、前の締めくくりを取り消し、最新の言葉の最後へ延期します。

## 余韻を残す短い旋律（試作）

締めくくりは、あらかじめ組んだ6種類の4音フレーズからランダムに選びます。直前と同じものは続けず、主音への着地や最後の低音和音は外しています。最後の発音は開始から1.64〜1.80秒で、残響へ静かに溶けます。

## ピアノ版の仮止め（2026-10-24）

現在のビジュアルと、実録ピアノ・長い残響・6種類からランダムに選ぶ短い締めくくりをまとめて、Gitタグ `yobana-piano-v6` として保存します。前のピアノ版 `yobana-piano-v5` も保持しています。

## ピアノの和音化（試作）

`yobana-piano-v6` を保持したまま、開花と締めくくりを3音の開いた和音に変更。旋律の上声を残し、下の2音は小さく添えます。6種類の短いフレーズと残響は維持しています。

## 採用版（2026-10-25）

`film-fireworks.html` を採用版としてmainに反映。柔らかなピアノ和音、一定の開花リズム、6種類の短い終わりの旋律、文字の重なりを抑える配置を使用しています。UIは音のON/OFFと入力を中心に整理し、日英併記・Cormorant Garamond・キーボード操作（入力欄からTab→Spaceで音を切り替え）に対応しました。フォントとOFLライセンスを `assets/fonts/` に同梱しています。保存タグは `yobana-adopted-v7`。
