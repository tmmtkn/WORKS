# YOBANA

文字が光と音になって夜空にほどける、ブラウザで動くインタラクティブ作品。

## 試す

インストールやビルドは不要です。音声ファイルを読み込むため、ローカルサーバーから開いてください。

ローカルサーバーを使う場合は、WORKS リポジトリのルートで以下を実行し、 http://localhost:8000/YOBANA/ を開きます。

```sh
python3 -m http.server 8000
```

## 操作

- 入力欄に文字を打つと、一文字ずつ花火になります。日本語は変換を確定したときに打ち上がります。
- 「音をひらく」で開花に合わせてゆっくり広がるアンビエント音が有効になります。
- マウス移動、または夜空を指でドラッグすると視点が変わります。
- 「視点をとめる」でカメラを固定できます。
- 「ひとひら試す」でデモ、「消す」で夜空と入力をクリアします。
- Enter で入力欄を空にできます。

## 仕組み

Canvas 2D に三次元座標を透視投影し、カメラの旋回・上下移動・距離の変化を表現しています。粒子と軌跡を空間内に保持するため、視点を動かすと奥行きによる見え方が変わります。音は Web Audio API でローカル録音の余韻を粒状に分解し、低速で重ねてアンビエント音に変化させます。打ち上げ時の効果音はありません。

外部ライブラリはありません。音声素材は作品フォルダに同梱し、外部サーバーへ通信しません。入力したことばはブラウザ内で処理されます。音源と利用条件は assets/audio/CREDITS.md を参照してください。
OS の「動きを減らす」設定が有効な場合、自動視点移動を初期状態で停止し、粒子数を減らします。

## 配置

```text
WORKS/
└── YOBANA/
    ├── index.html
    ├── README.md
    └── assets/audio/   # 実録の花火音と出典
```

Sites 固有の設定や認証情報を含まない、独立した作品フォルダです。

## 別案のプレビュー

`film.html` は「光の薄膜」の方向性を比較するための独立した試作です。ローカルサーバーで `/film.html` を開いてください。WebGLで透ける光の膜を描き、入力文字が膜の曲面に沿って浮かび、入力地点からたわみが伝わります。音は現在のアンビエント表現を共有します。本体の `index.html` は変更していません。

`film-fireworks.html` は「膜のなかの花火」の試作です。元の球状花火と文字の光を使い、前面の薄い膜に開花位置からたわみが伝わります。膜の色と濃度は控えめにし、アンビエント音を共有しています。元の2案は変更していません。

膜と花火の試作では、両者が同じ三次元座標とカメラを使います。開花の球状の広がりで膜を変形し、花火の色を膜へ反射させます。上昇中の光や膜の近くの火花も局所的に膜を照らします。

膜は現在、一枚の面ではなく、各花火の周囲に異なる向きで膨らむ局所的な曲面として描いています。輪郭を淡く消し、花火の色・光・広がりと連動して重なり、消えていきます。

描画は、火花の軌跡をまとめて描き、座標計算を共有するよう軽量化しています。膜は局所曲面ごとに光を計算し、背景タブではアニメーションを停止します。

## ビジュアル仮止め（2026-10-24）

現在の確認対象は `film-fireworks.html`。「膜のなかの花火」と、整列した細かなドットの膜を組み合わせたビジュアルを仮止めしています。Gitタグ `yobana-visual-v3` で戻せます。

- 入力前も、左右へ広がる薄い膜がゆっくり波打ちます。
- 花火の周囲に異なる向きの曲面が現れ、花火の色に合わせてドットと膜が光ります。
- 膜の縁は柔らかく消え、色・濃淡・彩度が穏やかに変化します。
- 日本語の変換確定では打ち上げず、確定後の別のEnterで言葉を送ります。
- 現在の音はアンビエント版です。実録の花火音を使う保存版は `yobana-prototype-v2` です。

以後は、このビジュアルを基準にして変更を進めます。
